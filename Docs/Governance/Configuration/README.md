# Configuration Management

Esta carpeta contiene los artefactos canónicos de Configuration Item Management.

## Fuente de verdad

- `Configuration-Item-Register.yml`: registro estructurado de CIs.
- `Configuration-Baseline-Register.yml`: registro de baselines.
- `Configuration-Status-Accounting.md`: estado y evolución.
- `Configuration-Audit-Checklist.md`: verificación/auditoría.

La política general se encuentra en `Docs/Governance/35-Configuration-Management.md`.

## Principio

Git conserva el historial de versiones. Configuration Management identifica y controla los elementos de configuración, sus baselines, dependencias, estados, aprobaciones y evidencias.
