# Data Governance

Esta carpeta contiene los artefactos controlados de Data Governance.

## Fuente normativa y metodológica

La capacidad se alinea, según aplicabilidad, con:

- ISO/IEC 38505-1:2026 — Governance of data.
- ISO/IEC TS 38505-3:2021 — Guidelines for data classification.
- ISO 8000-1:2022 — Data quality overview.
- ISO 8000-51:2023 — Data governance policy statements.
- ISO 8000-150:2022 — Data quality management roles and responsibilities.
- ISO/TS 8000-82:2022 — Data quality rules.
- NIST Privacy Framework 1.0.
- ISO/IEC/IEEE 12207:2026 y 15288:2023 para integración con ciclos de vida.

La selección de controles concretos se realizará conforme al contexto real del Ecosistema.

## Principio de población

No se crearán inventarios, propietarios, clasificaciones, reglas de calidad, retenciones, RPO/RTO o lineage ficticios. Los registros se poblarán a partir de evidencia de las fases de descubrimiento, requisitos, modelado, arquitectura e implementación.

## Artefactos previstos

- Data Inventory.
- Data Domain Catalog.
- Data Classification Matrix.
- Data Ownership Register.
- Data Quality Rule Catalog.
- Data Lineage Register.
- Retention Schedule.
- Access Matrix.
- Privacy Data Register.
- Backup and Recovery Register.
- Data Disposal Records.
