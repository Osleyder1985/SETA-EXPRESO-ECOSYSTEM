# Evaluación SoD de cambios

Todo cambio controlado debe responder:

1. ¿Qué riesgo tiene?
2. ¿Qué funciones se acumulan?
3. ¿Qué independencia exige ese riesgo?
4. ¿La combinación está permitida?
5. Si no, ¿existe una excepción formal?
6. ¿Qué control compensatorio aplica?
7. ¿Cuál es el riesgo residual?
8. ¿Qué evidencia demuestra la decisión?
