# Integración SoD con Change Control

Para todo cambio controlado, la evaluación de impacto y riesgo debe preceder a la determinación de independencia. El resultado se registra junto al cambio.

```text
Change → Impact Analysis → Risk → SoD → Approval → Execute → Verify → Validate
```

Cuando la segregación requerida no sea viable, debe existir una excepción formal con control compensatorio y riesgo residual.
