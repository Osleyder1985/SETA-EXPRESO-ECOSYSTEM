# Integración SoD con Configuration y Supplier Governance

## Configuration Management

Los cambios de configuración y baselines se clasifican por riesgo. Cuando corresponda, la aprobación de una configuración crítica debe estar separada de su ejecución y validación.

## Supplier / Third Party

La selección, aprobación y aceptación de un proveedor o componente de tercero se evalúan para determinar si requieren separación, especialmente cuando el impacto o criticidad sea alto.

Las excepciones se documentan mediante el registro SoD.
