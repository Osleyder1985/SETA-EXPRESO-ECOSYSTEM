# Integración SoD con Lifecycle

La segregación de funciones es transversal al ciclo de vida. Se activa cuando una actividad contiene decisiones o cambios cuyo riesgo requiere independencia.

Aplicación mínima:

```text
Concepción → Requisitos → Arquitectura → Diseño → Construcción
→ Integración/Verificación → Validación → Despliegue → Operación
→ Mantenimiento/Evolución → Retirada
```

La exigencia de independencia se determina por riesgo y criticidad de la actividad.
