# Integración SoD con Engineering Metrics

Las métricas SoD deben observar, cuando existan datos suficientes:

- cambios clasificados por riesgo;
- aplicación de independencia requerida;
- excepciones;
- controles compensatorios;
- conflictos de funciones;
- desviaciones detectadas posteriormente.

No se establecen valores históricos ficticios.
