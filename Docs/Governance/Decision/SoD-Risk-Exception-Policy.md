# Política de excepciones SoD

Una excepción existe cuando una combinación restringida o prohibida no puede segregarse por una limitación organizativa o contextual demostrable.

Toda excepción debe vincularse a un riesgo, justificarse, definir control compensatorio, registrar riesgo residual y establecer reevaluación.

Las excepciones de R4 requieren evidencia reforzada y escalamiento a la autoridad de decisión correspondiente.
