# Supplier / Third-Party Evidence Checklist

Para cada tercero material, recopilar según aplicabilidad:

- [ ] Identificación y servicio confirmado.
- [ ] Criticidad y owner definidos.
- [ ] Vendor Risk Assessment.
- [ ] Security Assessment.
- [ ] Contrato y términos aplicables.
- [ ] SLA / soporte.
- [ ] Condiciones de incident notification.
- [ ] Tratamiento y acceso a datos.
- [ ] Privacidad / DPA cuando corresponda.
- [ ] Subprocesadores / subproveedores relevantes.
- [ ] Licencia y obligaciones.
- [ ] Dependency / version / provenance.
- [ ] SBOM cuando corresponda.
- [ ] Continuidad y sustitución.
- [ ] Exit Strategy.
- [ ] Decisión / aprobación cuando sea material.
- [ ] Evidencia de onboarding.
- [ ] Evidencia de revisiones periódicas.
- [ ] Evidencia de terminación / salida cuando aplique.

## Regla

La ausencia de un documento no debe convertirse automáticamente en una conclusión de incumplimiento. Debe registrarse como evidencia ausente, no aplicable, pendiente o insuficiente según el contexto y el criterio de evaluación.
