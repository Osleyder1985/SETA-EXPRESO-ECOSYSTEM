# Decision Backlog

## Propósito

Este documento registra decisiones importantes pendientes del ecosistema SETA-EXPRESO-ECOSYSTEM durante la Fase 0.

No representa decisiones aprobadas ni sustituye los futuros Architecture Decision Records (ADR).

Su objetivo es evitar decisiones improvisadas y preparar la transición hacia la fase de arquitectura.

---

# Decisiones pendientes

## Arquitectura

- Tipo de aplicación.
- Arquitectura general del sistema.
- Infraestructura y modelo de despliegue.
- Lenguaje principal y stack tecnológico.

## Datos

- Motor de base de datos.
- Modelo inicial de datos.
- Estrategia de almacenamiento y evolución del modelo.

## Seguridad

- Modelo de autenticación.
- Modelo de autorización.
- Gestión de identidades y permisos.

## Estado

Todas las decisiones anteriores permanecen pendientes hasta contar con investigación, análisis técnico y evidencia suficiente.

Cuando una decisión sea tomada, deberá registrarse mediante un ADR formal.
