# Supplier / Third-Party Governance — Baseline Summary

**Issue:** #41  
**Estado:** Baseline documental inicial

La capacidad queda organizada en siete dominios:

1. Third-Party Register.
2. Vendor Risk.
3. SLA / Contractual Controls.
4. Security Assessment.
5. License Governance.
6. Dependency Governance.
7. Exit Strategy.

La integración transversal se documenta en `32-Supplier-Third-Party-Integration-Map.md` y la trazabilidad decisional en `33-Supplier-Third-Party-Decision-Integration.md`.

La baseline no contiene proveedores, contratos, riesgos, licencias o dependencias ficticias.
