# Modelo de evidencia SoD

La evidencia mínima de una decisión o cambio sujeto a SoD debe permitir reconstruir:

```text
qué se decidió
→ qué riesgo tenía
→ qué independencia requería
→ quién definió
→ quién ejecutó
→ quién aprobó
→ quién verificó
→ quién validó
→ qué excepción existió
→ qué riesgo residual quedó
```

La evidencia debe vincularse al artefacto o registro correspondiente y al cambio concreto.
