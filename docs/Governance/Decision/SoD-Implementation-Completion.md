# Criterio de completitud — SoD

**Issue:** #49  
**Problema:** #11

La capacidad documental se considera completa para esta unidad de cambio cuando existen: política, clasificación de riesgo, funciones controladas, matriz de combinaciones, controles, excepciones, checklist, análisis de impacto, integración y criterio de validación.

La operacionalización futura de los controles en otros procesos permanece como trabajo trazable y no se presenta como completada.
