# Segregation of Duties

Esta carpeta contiene la capacidad de gobernanza del Problema #11.

## Artefactos

- SoD-Decision-Function-Matrix.yml — funciones controladas.
- SoD-Risk-Independence-Matrix.yml — riesgo e independencia.
- SoD-Role-Combination-Matrix.yml — combinaciones permitidas/restringidas/prohibidas.
- SoD-Control-Matrix.yml — controles.
- SoD-Exception-Register.yml — registro de excepciones.
- SoD-Exception-Template.yml — plantilla de excepción.
- SoD-Approval-Record-Template.md — plantilla de aprobación.
- SoD-Review-Checklist.md — checklist operativo.
- SoD-Impact-Analysis.md — impacto.
- SoD-Integration-Register.md — **fuente canónica del registro de integración SoD y su estado de operacionalización**.
- SoD-Integration-Register-2.md — **trazabilidad complementaria; no es SoT ni mantiene una lista paralela**.
- SoD-Governance-Status.md — estado.

La política principal está en Docs/Governance/49-Segregation-of-Duties-Governance.md.
