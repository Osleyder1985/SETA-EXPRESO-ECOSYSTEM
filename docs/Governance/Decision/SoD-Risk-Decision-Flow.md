# Flujo de decisión basado en riesgo — SoD

```text
Decision / Change
       ↓
Impact Analysis
       ↓
Risk Classification
       ↓
SoD Classification
       ↓
┌───────────────┬──────────────────┬─────────────────┐
│ ALLOWED       │ RESTRICTED       │ PROHIBITED      │
│ continuar     │ revisar/condición│ segregar o      │
│ con evidencia │ adicional        │ excepcionar     │
└───────────────┴──────────────────┴─────────────────┘
       ↓
Approval / Execution / Verification / Validation
       ↓
Evidence
```

Una excepción requiere registro y tratamiento explícito del riesgo residual.
