# Matriz de trazabilidad SoD

| Elemento | Fuente | Salida |
|---|---|---|
| Riesgo | Risk Register | Risk Level |
| Riesgo | Risk Level | Independence Requirement |
| Roles | Decision Authority | Function Combination |
| Function Combination | SoD Matrix | ALLOWED/RESTRICTED/PROHIBITED |
| Restricted/Prohibited | Exception Register | Exception + Compensating Control |
| Decision/Change | SoD Assessment | Evidence |
| Evidence | Validation | Baseline decision |

Cada fila representa una relación trazable y no una afirmación de ejecución automática.
