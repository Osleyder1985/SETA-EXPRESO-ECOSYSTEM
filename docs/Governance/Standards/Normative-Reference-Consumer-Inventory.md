## Reglas de control

1. El registro YAML es la fuente de verdad para identificador, edición y estado.
2. Los consumidores deben referenciar los identificadores controlados.
3. Un cambio de edición requiere análisis de impacto y actualización coordinada.
4. Un DIS, CD o borrador no sustituye una edición publicada.
5. Una referencia histórica debe permanecer etiquetada como histórica/reemplazada.
6. Toda discrepancia constituye drift y requiere Issue → Branch → Commit → Validation → Review → PR → Merge.

La cobertura exhaustiva de todos los artefactos de Governance sigue pendiente y no se infiere ausencia de referencias.
